# 🌿 Сам збіраю — Инструкция по настройке

## Файлы сайта
- `index.html` — главная страница со списком объявлений
- `dobavit.html` — страница для добавления объявлений (Google Форма)

---

## Шаг 1 — Сделать Google Таблицу публичной

1. Откройте вашу таблицу «Сам збіраю» в Google Sheets
2. Нажмите «Настройки доступа» (кнопка вверху справа)
3. В разделе «Общий доступ» выберите «Все, у кого есть ссылка»
4. Убедитесь, что стоит режим «Читатель» (не «Редактор»)
5. Нажмите «Готово»

---

## Шаг 2 — Найти ID таблицы и GID листов

Откройте таблицу в браузере. URL выглядит так:
https://docs.google.com/spreadsheets/d/SHEET_ID/edit#gid=GID

- **SHEET_ID** — длинный код между /d/ и /edit
- **GID для Фермы** — число после #gid= когда вы на листе «Фермы»
- **GID для Урожаи** — число после #gid= когда вы на листе «Урожаи»

---

## Шаг 3 — Вставить ID в index.html

Откройте `index.html` и найдите эти строки вверху скрипта:

```javascript
const SHEET_ID  = 'YOUR_SHEET_ID_HERE';
const FARMS_GID = '0';
const CROPS_GID = 'YOUR_CROPS_GID_HERE';
```

Замените:
- `YOUR_SHEET_ID_HERE` → ваш SHEET_ID
- `0` → GID листа Фермы
- `YOUR_CROPS_GID_HERE` → GID листа Урожаи

---

## Шаг 4 — Создать Google Форму для фермеров

1. Перейдите на forms.google.com
2. Создайте новую форму со следующими полями:
   - Тип хозяйства (выпадающий список: Ферма / Дача)
   - Название / Имя (текст)
   - Телефон (текст, подсказка: начинается с +375)
   - Telegram (текст, необязательно)
   - Культура (выпадающий список: Клубника, Малина, Смородина...)
   - Сезон с (дата)
   - Сезон по (дата)
   - Дни (выпадающий список: Ежедневно / Будние / Выходные / По договорённости)
   - Время (выпадающий список: Утро / День / Весь день / По договорённости)
   - Условия оплаты (выпадающий список: за кг / за ведро / Договорная / Бесплатно)
   - Цена подробнее (текст, необязательно)
   - Тип карты (выпадающий список: Яндекс Карты / Google Maps)
   - Ссылка на карту (текст)
   - Фото (загрузка файла, необязательно)
   - Расстояние от Минска (текст, напр: ~35 км)
   - Описание (длинный текст, необязательно)

3. Подключите форму к вашей таблице:
   - Нажмите вкладку «Ответы»
   - Нажмите иконку Google Sheets
   - Выберите «Выбрать существующую таблицу» → «Сам збіраю»

4. Получите ссылку для встраивания:
   - Нажмите «Отправить»
   - Вкладка «<>»
   - Скопируйте URL из src="..."

5. Вставьте URL в `dobavit.html`, заменив `YOUR_GOOGLE_FORM_EMBED_URL_HERE`

## Шаг 5 — Опубликовать на GitHub Pages (бесплатно)

1. Зайдите на github.com и создайте бесплатный аккаунт
2. Нажмите «New repository» (новый репозиторий)
3. Назовите его `samzbivayu` (или любое другое имя)
4. Сделайте его Public (публичным)
5. Нажмите «Create repository»
6. Нажмите «uploading an existing file»
7. Перетащите оба файла: index.html и dobavit.html
8. Нажмите «Commit changes»
9. Перейдите в Settings → Pages
10. В разделе Source выберите «Deploy from branch» → main → / (root)
11. Нажмите Save

Через 1-2 минуты сайт будет доступен по адресу:
https://ВАШ_ЛОГИН.github.io/samzbivayu/

---

## Шаг 6 — Модерация объявлений

Когда фермер заполняет форму:
1. Данные появляются в вашей Google Таблице на новом листе «Ответы формы»
2. Вы проверяете данные
3. Копируете нужные поля в листы «Фермы» и «Урожаи»
4. Ставите Одобрено = TRUE
5. Объявление появляется на сайте автоматически

## Частые вопросы

**Как обновить список объявлений?**
Просто редактируйте Google Таблицу — изменения появятся на сайте через несколько секунд.

**Как добавить новые культуры в фильтры?**
Откройте index.html и найдите раздел с чипами (chips). Добавьте новую строку по аналогии.

**Как подключить собственный домен?**
В GitHub Pages → Custom domain введите ваш домен и следуйте инструкции.
